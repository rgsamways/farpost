# Lightbulbs

One file per idea that isn't ready to build yet — per `docs/standard-methodology.md` rule 6: "a lightweight place to capture ideas that aren't ready to build yet... so nothing gets lost between when it's noticed and when there's time to scope it."

Naming convention, carried over from the old Farpost repo's own established pattern (confirmed in memory, not guessed): `farpost-lb-<short-slug>.md`. Not `rsw-lb-` — that prefix is robinsamways.ca's own convention for its cross-project dev-log entries, a different thing.

None of the pre-rebuild lightbulb files carry forward automatically — per `CLAUDE.md`'s guard rule, an idea from `farpost-legacy` gets a fresh file here only if it's still actually wanted, not copied over by default just because it once existed.

No entries yet as of 2026-07-26 — this folder is part of the rebuild's foundational setup, created before any code exists.
